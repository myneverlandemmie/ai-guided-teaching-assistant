# V0.2 Scope / V0.2 功能边界

## 中文说明

V0.2 的目标不是建设完整教务系统，而是完成一个“可演示、可部署、可申报案例”的 SQL 课程 AI 导学与自动批阅闭环。

传播上采用三层模式：

1. 项目方云端演示；
2. 普通教师 Windows 单机体验；
3. 学校或教师自有服务器私有部署。

## English Summary

V0.2 is not intended to be a full educational administration system. Its goal is to deliver a demo-ready, deployable, and case-report-ready AI-guided SQL learning and assessment workflow.

The project supports three usage modes:

1. Project-owned cloud demo;
2. Windows local demo for ordinary teachers;
3. Private server deployment for real classroom use.

## 核心流程 / Core Workflow

当前代码已完成到“Mock AI 知识主干初稿生成与教师编辑保存”。后续 SQL 作业、小测题、导学案、学习总结仍是计划范围，不应在文档或演示中描述为已完成。

```text
课程计划上传
→ 自动拆解课次
→ 上传课次材料
→ Mock AI 生成知识主干初稿
→ 教师编辑保存知识主干
→ 后续接入真实 AI 生成小测题和分层导学案
→ 后续学生提交 SQL 作业
→ 后续系统自动批阅
→ 后续教师复核
→ 后续生成学习总结
```

```text
Course plan upload
→ planned lesson parsing
→ lesson material upload
→ AI knowledge outline
→ quiz generation
→ leveled guidebook generation
→ SQL assignment submission
→ auto grading
→ teacher review
→ learning summary
```

## Current Limitations / 当前限制

- 当前没有完整注册 / 登录功能；
- 当前使用 demo course / demo teacher 作为开发临时上下文；
- V0.2 后续必须提供测试教师账号、测试学生账号、测试班级；
- 当前知识主干仍是 Mock AI，不可作为最终案例中的真实 AI 生成成果；
- 后续真实导学案、小测题、总结等应接入真实 API；
- 当前不实现 OCR；
- 当前不解析 PDF、图片、扫描件、旧版 `.doc/.ppt`；
- 当前不实现复杂 Vue / React 前端；
- 当前不实现完整教务系统；
- 当前不承接外部教师真实班级大规模使用项目方服务器。

## Account and Trial Boundary / 账号与试用边界

开发阶段暂用 demo course / demo teacher。该方式只用于本地开发和功能串联，不作为最终试用方式。

V0.2 演示 / 部门内试用阶段应提供：

- 测试教师账号；
- 测试学生账号；
- “演示班级”或“测试班级”；
- 教师创建测试班级的能力；
- 学生使用测试账号进入班级查看导学内容或提交演示作业的能力。

学生不需要填写 API Key。教师如需真实 AI 生成功能，应使用自己的 API Key。

API Key 边界：

- 平台不提供公共 Token；
- 平台不做 Token 转售；
- API Key 不应明文入库；
- API Key 不应写入日志；
- API Key 不应提交到 Git；
- API Key 不能只存 hash，因为 hash 无法还原，不能用于真实 API 调用；
- V0.2 推荐“教师登录后，会话级临时 API Key”，服务端内存临时保存，退出 / 清除 / 服务重启后失效；
- 长期保存 Key 需要另行设计加密存储方案，不在当前阶段实现。

## Python MVP Add-on / Python 基础题批阅加分原型

Python 批阅在 V0.2 中不是主线功能，不替代 SQL / MySQL 教学闭环。它只是加分原型，用于演示系统未来可以扩展到 Python 入门课程。

V0.2 的优先级仍然是 SQL 主线：课程计划上传、课次拆解、导学案、小测题、SQL 作业、自动批阅、教师复核和学习总结。

Python 基础题批阅原型只面向中职学生的入门内容，包括：

- `print` 输出；
- `input` 输入；
- 变量赋值；
- 基础数据类型；
- `if` 条件判断；
- `for` / `while` 简单循环；
- `def` 函数入门；
- 形参与实参；
- 输入输出格式；
- 简单字符串与数字处理。

V0.2 Python 原型最多支持：

- 单文件 `.py`；
- 在线粘贴代码或上传 `.py`；
- 简单输入输出题；
- 固定测试用例；
- 捕获 `stdout`；
- 捕获 `stderr`；
- 超时控制；
- 基础错误类型识别；
- 教师复核。

V0.2 Python 原型不支持：

- 多文件项目；
- 第三方库；
- 图形界面；
- 网络访问；
- 数据库访问；
- 文件读写题；
- 复杂单元测试框架；
- 长时间运行程序；
- 自动代写答案。

推荐流程：

```text
学生提交 Python 代码
→ 系统在受限环境中运行
→ 输入测试用例
→ 捕获 stdout / stderr
→ 判断输出是否匹配
→ 识别错误类型
→ 生成初步反馈
→ 教师复核
→ 学生查看最终反馈
→ 记录学习错误数据
```

## Learning Error Data Seed / 学习错误数据开端

V0.2 可以在 SQL 批阅和 Python 基础题批阅原型中，同步沉淀学习错误数据。该设计不是为了监控学生，而是为了帮助教师理解常见错误、优化导学案、调整课堂讲解和改进教学反馈。

学习错误数据开端可记录：

- 学生提交内容；
- 作业类型；
- 测试用例结果；
- `stdout`；
- `stderr`；
- 自动识别错误类型；
- 系统初评；
- 教师最终评分；
- 教师修正反馈；
- 教师标注的错误类型；
- 是否需要后续辅导；
- 是否可作为脱敏样本进入教学错误数据集。

数据边界：

- 公开仓库不得包含真实学生数据；
- 案例材料中只能使用演示数据或脱敏数据；
- 数据集建设是后续拓展方向，V0.2 只做开端；
- 项目方演示服务器不得承接外部真实班级的大规模数据沉淀。

## Confirmed Python MVP Limits / Python MVP 已确认限制

Python MVP 已确认只演示 1-2 道基础题：

1. `input + if` 判断：输入成绩，判断是否及格；
2. `for` 循环求和：输入 `n`，计算 `1` 到 `n` 的和。

教师错误标注第一版采用“主错误类型单选 + 教师补充说明文本”，暂不做多标签。

`can_enter_dataset` 默认值必须为 `false`。只有教师手动勾选后，样本才允许作为脱敏样本进入教学错误数据集。
