# V0.2 Scope / V0.2 功能边界

## 中文说明

V0.2 的目标不是建设完整教务系统，而是完成一个“可演示、可部署、可申报案例”的 SQL 课程 AI 导学与自动批阅闭环。

传播上采用三层模式：

1. 项目方云端演示；
2. 普通教师 Windows 单机体验；
3. 学校或教师自有服务器私有部署。

## English Summary

V0.2 is not intended to be a full educational administration system. Its goal is to deliver a demo-ready, deployable, and case-report-ready AI-guided SQL learning and assessment workflow.

The project supports three usage modes:

1. Project-owned cloud demo;
2. Windows local demo for ordinary teachers;
3. Private server deployment for real classroom use.

## 核心流程 / Core Workflow

```text
课程计划上传
→ 自动拆解课次
→ 上传课次材料
→ AI 生成知识主干
→ 生成小测题
→ 生成分层导学案
→ 学生提交 SQL 作业
→ 系统自动批阅
→ 教师复核
→ 生成学习总结
```

```text
Course plan upload
→ planned lesson parsing
→ lesson material upload
→ AI knowledge outline
→ quiz generation
→ leveled guidebook generation
→ SQL assignment submission
→ auto grading
→ teacher review
→ learning summary
```

- Demo student accounts / 创建演示学生账号

- Course plan parsing preview / 授课计划解析预览

- Lesson material upload / 上传课次教学材料
- AI generation service wrapper / AI 生成服务封装
- Mock AI mode / Mock AI 演示模式
- SQL assignment submission / SQL 作业提交
- SQL grading service / SQL 自动批阅
- Teacher review / 教师复核
- Student feedback page / 学生反馈页面
- Windows quickstart script / Windows 快速启动脚本预留
- Linux deployment guide / Linux 部署文档

## 暂不进入 V0.2 主线 / Out of Scope

- Full Python grading / 完整 Python 自动批阅
- OCR screenshot correction / OCR 拍照纠错
- Complex frontend SPA / 复杂前端单页应用
- GPU local model deployment / GPU 本地模型部署
- Full integration with external learning platforms / 与外部学习平台深度集成
- Hosting real external classes on the project owner's demo server / 让外部真实班级使用项目方演示服务器
