# V0.2 Scope / V0.2 功能边界

## 项目定位

智学导评 V0.2 的定位是：面向中职教师的 AI 辅助教学设计分析与导学案生成系统。

V0.2 不建设完整教务系统，不建设学生端答题系统，不包装为自动备课、一键生成完整教案或作业全自动处理系统。所有生成内容均为教师审阅用草稿，必须由教师修改、确认后使用。

## 当前主流程

当前已实现的主流程为：

```text
课程管理
→ 课程计划上传
→ 正式课次生成
→ 课次资料上传与文本提取
→ 课程资料整理 V2
→ 知识主干生成与教师编辑
→ 备课参考建议
→ 课前学情测试 V2
→ 题卡预览、单题编辑/删除、学习通习题文件导出
→ 学生导学案 V2
→ 全班通用导学案、巩固提升任务包、拓展探究任务包
→ Markdown 下载
→ 教师审阅、修改、确认后使用
```

课次资料支持 `txt`、`md`、`docx`、`pptx`、`xlsx`。当前不支持 `xls`、PDF、图片、扫描件和 OCR。

## V2 页面边界

推荐演示入口：

- `/ui-v2/courses`：课程中心 V2；
- `/courses/{course_id}/lessons`：正式课次列表，作为 V2 过渡入口；
- `/ui-v2/lessons/{lesson_id}/materials-outline`：课程资料整理 V2；
- `/ui-v2/lessons/{lesson_id}/diagnostic-probe`：课前学情测试 V2；
- `/ui-v2/lessons/{lesson_id}/learning-guides`：学生导学案 V2。

旧页面作为 legacy / 兼容页面保留，用于测试、回退和过渡入口。案例提交前不建议移动或删除旧模板；后续完全切换到 V2 后，再单独安排旧 UI 归档。

- 页面不显示服务器绝对路径；
- 会话级 DeepSeek API Key 设置、掩码显示、清除和模型选择；
- DeepSeek Provider；
- 知识主干生成、编辑和保存；
- 生成前基础行政信息过滤；
- 备课参考建议；
- 课前学情测试 V2；
- 题卡预览、单题编辑、单题删除；
- 学习通习题文件导出；
- 学生导学案 V2；

## 未实现与预留

当前尚未实现：

- 完整登录权限体系；
- 学生端；
- 学习通 API；
- 作业批阅后端；
- 自动评分 route；
- 新的作业评分数据库表或字段；
- OCR、PDF、图片、扫描件解析；
- 复杂前端单页应用；
- 面向外部真实班级的公开生产服务。

作业批阅只能作为预留功能和后续探索方向描述。后续可探索面向编程类、数据库类作业的规则测试与 AI 辅助评语草稿，但结果仅供教师参考，需教师审核确认后使用。

不得描述为已完成自动评分、已有学生端、自动发布评语或自动评价学生。

## API Key 与 AI 边界

教师在 `/ai/settings` 中填写自己的 DeepSeek API Key。Key 只保存在当前会话的服务端内存中，不写入数据库、不写入 cookie、不写入日志，也不得提交到 Git。

模型选择建议：

- `deepseek-v4-flash`：适合快速预览和页面流程验证；
- `deepseek-v4-pro`：适合正式生成、任务包和备课参考建议。

所有 AI 或本地结构化输出都必须保留“教师审阅、修改、确认后使用”的边界。
