# Prompt 文件说明

## 目录用途

`docs/prompts/` 用于保存智学导评 V0.2 的重要生成提示词说明和施工边界文档。这些文件帮助教研团队理解系统如何约束知识主干、备课参考建议、课前学情测试、学生导学案等内容的输出风格和结构。

这里的文件不提供页面内编辑功能，也不建议普通使用者把修改 prompt 当作日常操作。一般教师使用系统时，应优先通过页面上传资料、生成草稿、人工审阅和修改结果。

## 当前文件清单

- `knowledge-outline-generation-v0.2.md`：知识主干生成相关提示词与边界说明，用于约束知识结构、课程思政与职业素养融入点、可测知识点和补充内容建议等输出。
- `teaching-prep-reference-suggestions-v0.1.md`：备课参考建议相关提示词说明，用于约束课堂设计、教学准备、活动建议和教师参考内容的生成方向。
- `codex-build-prompt.md`：给后续工程维护和文档施工使用的 Codex 施工提示，说明项目定位、已实现范围、预留功能和禁止扩展边界。

## 修改建议

教研团队如需校本化调整，可根据学校课程、专业方向、教学材料要求和案例申报口径，小范围修改相关 prompt 文件。

建议遵守以下原则：

1. 修改前先备份原文件。
2. 每次只改一小段，便于判断生成效果变化。
3. 修改后重新启动服务。
4. 手动验证知识主干、备课参考建议、课前学情测试和学生导学案等生成结果。
5. 如果输出格式混乱、边界变差或内容不符合教学要求，应恢复原 prompt 文件。

普通使用者不建议随意修改 prompt 文件。页面中生成的内容本身仍是草稿，教师可直接在系统页面或下载后的 Markdown 中审阅和调整。

## 安全边界

不要在任何 prompt 文件中写入：

- DeepSeek API Key 或其他密钥；
- 学生姓名、学号、手机号、身份证号等个人隐私；
- 教师个人隐私；
- 学校内部未公开敏感材料；
- 真实成绩、真实班级名单或其他敏感数据。

prompt 文件可能进入 Git 仓库和案例材料检查范围。公开发布前，应再次确认其中不包含 API Key、真实隐私数据或未授权材料。
