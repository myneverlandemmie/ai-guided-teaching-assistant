# QA 检查表

本检查表用于 Codex 施工、人工验收和演示准备。每轮按实际变更范围选择检查项，不能把未检查内容写成已通过。

## 功能检查

- [ ] 默认演示入口 `/ui-v2/courses` 可打开。
- [ ] 课程新建、重命名、删除流程符合当前预期。
- [ ] 授课计划上传、解析、预览、确认 / 跳过流程可用。
- [ ] 正式课次列表和课次详情页可用。
- [ ] 课次资料粘贴、上传、多文件上传、删除流程可用。
- [ ] 支持格式 `txt`、`md`、`docx`、`pptx`、`xlsx` 的文本提取符合当前预期。
- [ ] 不支持格式 `xls`、PDF、图片、扫描件、旧版 `.doc/.ppt` 的边界提示符合当前预期。
- [ ] AI 设置页可保存、显示掩码、清除会话级 API Key 和模型选择。
- [ ] 知识主干生成、编辑、保存流程可用。
- [ ] 备课参考建议流程可用。
- [ ] 课前学情测试 V2 生成、预览、单题编辑、单题删除流程可用。
- [ ] 学习通习题文件导出为文件下载，不描述为学习通 API 直连。
- [ ] 学生导学案 V2、巩固提升任务包、拓展探究任务包生成和 Markdown 下载流程可用。
- [ ] 本地结构化草稿 / fallback 被描述为教师初稿和演示兜底，不描述为真实 AI 成果。

## UI / 中文文案检查

- [ ] 页面中文文案符合“中职教师教学设计辅助”定位。
- [ ] 不出现“学生端已完成”“自动批阅已完成”“自动评分已完成”“学习通 API 直连已完成”等误导表述。
- [ ] AI 输出均标注为教师草稿或需教师审阅确认的内容。
- [ ] 页面不显示服务器绝对路径。
- [ ] 表单字段名称、按钮含义、redirect 后提示与当前流程一致。
- [ ] V2 页面作为推荐演示入口，旧页面仅作为 legacy / 兼容入口处理。

## 数据与文件安全检查

- [ ] 不提交 API Key、真实学校 / 教师 / 班级 / 学生信息或其他敏感数据。
- [ ] 不修改或删除数据库文件。
- [ ] 不修改或删除上传文件、导出文件等运行产物。
- [ ] 不擅自运行清理脚本或破坏性命令。
- [ ] API Key 仍保持会话级临时存储，不写数据库、不写 cookie、不写日志。
- [ ] 导出文件路径和下载行为不暴露服务器绝对路径。

## 测试检查

- [ ] 代码变更后运行 `cd backend && PYTHONPATH=. ../.venv/bin/pytest -q`。
- [ ] 仅文档变更时，可不运行 pytest，但收工汇报必须明确说明原因。
- [ ] 测试失败时记录失败命令、失败摘要和未解决风险。
- [ ] route 拆分后重点检查 path、模板名称、表单字段、redirect 行为不变。
- [ ] 不改变已有测试夹具和演示数据语义。

## Git 提交前检查

- [ ] 已运行 `git status --short --branch`。
- [ ] 只修改本轮允许范围内的文件。
- [ ] 未主动 commit，除非用户明确要求。
- [ ] 未混入无关 UI、后端、数据库、文档或运行产物改动。
- [ ] 新增文件路径和命名符合现有项目结构。
- [ ] 如发现用户已有未提交改动，未擅自覆盖或回退。

## 演示准备检查

- [ ] 推荐入口仍为 `/ui-v2/courses`。
- [ ] 演示数据不包含真实敏感信息。
- [ ] DeepSeek API Key 由教师或演示者临时填写，不写入文档或代码。
- [ ] 已确认生成失败时 fallback 的展示口径。
- [ ] 已确认学习通导出只是习题文件导出，不是自动发布。
- [ ] 已确认作业批阅仅为后续探索方向。

- [ ] 汇报各文件做了什么。
- [ ] 汇报 pytest 或其他测试结果；未运行时说明原因。
- [ ] 汇报是否存在风险点。
- [ ] 汇报是否需要人工手工验收。
- [ ] 给出下一步建议。
