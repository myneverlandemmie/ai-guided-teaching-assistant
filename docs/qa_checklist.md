本检查表用于 Codex 施工、人工验收和演示准备。每轮按实际变更范围选择检查项，不能把未检查内容写成已通过。

## 手工验收重点

- [ ] 课次资料上传错误：不支持格式、空 `.xlsx`、超限文件均显示中文提示，不展示 traceback 或服务器路径。
- [ ] 授课计划上传错误：非 `.xlsx`、超限 `.xlsx` 均显示中文提示，失败时不生成错误课次。
- [ ] AI fallback 提示：无 DeepSeek API Key 和 AI 服务不可用时显示对应 warning / notice 提示，输出明确为教师草稿。
- [ ] `return_to` 非法提示：非法返回地址回到课程中心，并显示“返回地址无效，已返回课程中心。”。
- [ ] 学习通导出成功 / 失败提示：成功时生成题库模板下载入口；失败时显示“习题文件导出失败，请检查题卡内容后重试。”。
- [ ] Markdown 下载：可下载 `.md`，下载失败时显示“下载文件生成失败，请重新生成或稍后再试。”。
- [ ] DOCX 下载：可下载 `.docx`，基础标题、段落、列表、加粗、行内代码、代码块可读可编辑；失败时显示中文友好提示。
- [ ] API Key 不回显：设置页只显示掩码，不在页面、日志、文档、数据库或提交中出现完整 Key。
