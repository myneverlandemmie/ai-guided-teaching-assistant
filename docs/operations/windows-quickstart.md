# Windows Quickstart / Windows 单机体验指南

## 中文说明

Windows 单机体验模式面向普通教师，用于低门槛验证智学导评 V0.2 的教师端主流程。它不是正式生产部署方案，而是“先看懂、先跑起来、先验证”的体验路径。

## 目标 / Goals

- 推荐使用 WSL2 + Ubuntu；
- 不要求掌握 Linux 运维；
- 使用浏览器访问本地系统；
- 可以上传授课计划；
- 可以体验课程资料整理、知识主干、备课参考建议、课前学情测试和学生导学案流程。

当前代码已支持的本地体验内容：

- 课程中心 V2；
- 课程管理；
- `.xlsx` 授课计划上传；
- 课程计划解析和 planned lessons 预览；
- planned lessons 确认 / 跳过；
- 生成正式课次；
- 正式课次列表和详情页；
- 粘贴或上传课次材料；
- `.txt` / `.md` / `.docx` / `.pptx` / `.xlsx` 资料文本提取；
- 多文件上传和删除材料；
- 知识主干生成、编辑和保存；
- 备课参考建议；
- 课前学情测试 V2；
- 题卡预览、单题编辑/删除、学习通习题文件导出；
- 学生导学案 V2；
- 全班通用导学案、巩固提升任务包、拓展探究任务包；
- Markdown 下载。

当前尚不支持完整登录权限、学生端、学习通 API、作业批阅后端或自动评分 route。

## 预期启动方式 / Expected Startup

当前推荐从项目根目录双击：

```bat
start_v2_courses.bat
```

教师双击后启动本地服务，然后在浏览器打开：

```text
http://127.0.0.1:8000/ui-v2/courses
```

## 简化策略 / Simplification Strategy

- 本地体验模式可使用 SQLite 存储系统数据；
- 如使用真实 AI，教师应填写自己的 API Key；
- V0.2 使用会话级临时 API Key，退出 / 清除 / 服务重启后失效；
- API Key 不应明文入库、写入日志或提交到 Git；
- 多人长期使用建议部署到自有服务器。

## 注意事项 / Notes

Windows 单机体验模式只适合本地演示和流程验证，不建议用于正式班级长期教学。

作业批阅仅作为后续探索方向，不应写成已实现能力。所有 AI 输出和本地结构化草稿都需要教师审阅、修改、确认后使用。
