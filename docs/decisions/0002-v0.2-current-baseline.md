# ADR 0002 V0.2 Current Baseline / ADR 0002 V0.2 当前基线

## Status / 状态

Accepted / 已接受

## Context / 背景

项目已经完成前 7 轮施工，代码状态从“课程计划导入原型”推进到“课次材料入口 + Mock AI 知识主干生成”。为了避免后续施工和案例文档误把未实现功能写成已实现功能，需要建立一个当前基线决策。

## Decision / 决策

当前基线确认如下：

- 已实现课程计划上传、解析、预览、确认 / 跳过和正式课次生成；
- 已实现正式课次列表和详情页；
- 已实现课次材料粘贴、上传、基础文本提取、多文件上传、删除和默认标题；
- 已实现 `.docx` 基础文本提取；
- 已实现 `.pptx` 实验性文本提取；
- 已实现 Mock AI 知识主干生成、编辑和保存；
- 已实现知识主干生成前的基础行政信息过滤；
- 当前相关测试最后一次运行结果为 `50 passed`。

当前未实现：

- 完整注册 / 登录；
- 测试教师账号、测试学生账号、测试班级；
- 真实 AI API；
- 导学案生成；
- 小测题生成；
- SQL 作业提交和自动批阅；
- 学习总结；
- OCR；
- Python 批阅；
- 复杂 Vue / React 前端。

## Account Trial Decision / 试用账号决策

当前开发阶段暂用 demo course / demo teacher。这只是临时开发上下文，不是最终试用方式。

V0.2 演示 / 部门内试用阶段必须提供测试教师账号、测试学生账号和演示班级 / 测试班级。学生不需要填写 API Key。

## API Key Decision / API Key 决策

教师使用自己的 API Key。平台不提供公共 Token，不做 Token 转售。

V0.2 推荐“教师登录后，会话级临时 API Key”：

- 服务端内存临时保存；
- 退出 / 清除 / 服务重启后失效；
- 不明文入库；
- 不写日志；
- 不提交到 Git。

API Key 不能只存 hash，因为 hash 无法还原，不能用于真实 API 调用。

长期保存 Key 需要另行设计加密存储方案，不在当前阶段实现。

## Consequences / 影响

- 文档和演示必须把 Mock AI 知识主干描述为流程演示，而不是真实 AI 成果；
- 后续施工应优先补账号、班级和会话级 API Key；
- 项目方演示服务器仍只用于案例展示和部门内演示，不承接外部教师真实班级大规模试用；
- 公开仓库只允许演示数据、虚构账号和程序生成的测试样例，不允许真实学校、教师、班级、学生或 API Key 信息。
