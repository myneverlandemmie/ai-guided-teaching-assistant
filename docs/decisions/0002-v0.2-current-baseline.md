# ADR 0002 V0.2 Current Baseline / ADR 0002 V0.2 当前基线

## Status / 状态

Accepted / 已接受

## Context / 背景

项目已经推进到 V2 教师端主流程。为了避免后续施工和案例文档误把预留功能写成已实现功能，需要更新当前基线决策。

## Decision / 决策

当前基线确认如下：

- 已实现课程计划上传、解析、预览、确认 / 跳过和正式课次生成；
- 已实现正式课次列表和详情页；
- 已实现课次材料粘贴、上传、基础文本提取、多文件上传、删除和默认标题；
- 已实现 `txt` / `md` / `docx` / `pptx` / `xlsx` 资料文本提取；
- 已实现课程中心 V2；
- 已实现课程资料整理 V2；
- 已实现知识主干生成、编辑和保存；
- 已实现备课参考建议；
- 已实现课前学情测试 V2；
- 已实现题卡预览、单题编辑/删除和学习通习题文件导出；
- 已实现学生导学案 V2；
- 已实现全班通用导学案、巩固提升任务包、拓展探究任务包和 Markdown 下载；
- 已实现知识主干生成前的基础行政信息过滤；
- 当前相关测试结果以本轮实际 pytest 输出为准。

当前未实现：

- 完整注册 / 登录；
- 学生端；
- 学习通 API；
- 作业批阅后端；
- 自动评分 route；
- OCR；
- PDF、图片、扫描件、旧版 `.doc/.ppt`、`xls` 解析；
- 复杂 Vue / React 前端。

## Account Trial Decision / 试用账号决策

当前开发阶段暂用本地演示上下文串联流程。这不是完整登录权限体系，也不是学生端。

## API Key Decision / API Key 决策

教师使用自己的 API Key。平台不提供公共 Token，不做 Token 转售。

V0.2 使用会话级临时 API Key：

- 服务端内存临时保存；
- 退出 / 清除 / 服务重启后失效；
- 不明文入库；
- 不写日志；
- 不提交到 Git。

API Key 不能只存 hash，因为 hash 无法还原，不能用于真实 API 调用。

长期保存 Key 需要另行设计加密存储方案，不在当前阶段实现。

## Consequences / 影响

- 文档和演示必须把本地结构化草稿和 fallback 描述为流程演示与教师初稿准备，不是真实 AI 成果；
- 后续施工应优先保持 V2 主流程稳定；
- 项目方演示服务器仍只用于案例展示和部门内演示，不承接外部教师真实班级大规模试用；
- 公开仓库只允许演示数据、虚构账号和程序生成的测试样例，不允许真实学校、教师、班级、学生或 API Key 信息。
