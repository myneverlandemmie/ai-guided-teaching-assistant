## 4. DOCX 下载 V0.1 完成项

Day 12.1 已完成基础 DOCX 下载 V0.1。

已完成内容：

- 为导学案 / 任务包 / 备课参考建议等草稿提供 `.docx` 下载。
- DOCX 文档包含系统标识、教师草稿提示、课程 / 课次信息和草稿正文。
- 支持标题、普通段落、列表、加粗、行内代码和代码块。
- 代码块以基础等宽字体和浅灰底展示。
- 文件生成失败时返回中文友好提示，不展示 traceback 或服务器路径。

保留边界：

- DOCX V0.1 是基础可编辑稿，不是精排模板。
- 暂不支持复杂 Markdown 完整转换。
- 暂不支持表格完整转换、图片、超链接、脚注、数学公式、HTML、代码高亮和复杂模板样式。
- 仍建议人工用 Word / WPS 打开代表性样例验收。

## 6. 保留边界

产品边界：

- 本项目面向中职教师，不面向学生端直接使用。
- 本项目是 AI 辅助教学设计分析与导学案生成系统，不是自动备课系统。
- 本项目不是自动批阅平台。
- 本项目不用于教师能力评价。
- 所有 AI 输出和本地 fallback 输出均为教师草稿，必须由教师审阅、修改、确认后再使用。

安全边界：

- API Key 会话级临时保存，不入库，不回显完整 Key。
- 不应把本地演示配置无认证暴露到公网。
- 不应提交运行时数据库、上传文件、导出文件或真实敏感数据。
- 学习通能力仅为题库模板导出，不是 API 直连或自动发布。
- 系统不自动发布内容给学生。

工程边界：

- `backend/app/main.py` 不应重新堆入业务 route。
- 新 route 应继续放在 `backend/app/routes/`。
- 业务编排和可复用逻辑优先放在 `backend/app/services/`。
- 导出相关逻辑优先放在 `backend/app/services/exports/` 或 `backend/app/routes/exports.py`。
- Prompt 模板和提示词文档继续放在 `docs/prompts/`。
