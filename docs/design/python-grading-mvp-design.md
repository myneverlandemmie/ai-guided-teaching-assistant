# Python Grading MVP Design / Python 基础题批阅原型设计

## 1. Positioning / 定位

Python 批阅在 V0.2 中不是已实现主线功能，只能作为后续探索方向。当前系统主线是课程、课次、资料、知识主干、备课参考建议、课前学情测试和学生导学案。

该原型面向中职学生的 Python 入门学习，不处理复杂项目文件，不处理第三方库，不处理图形界面、网络请求或数据库连接。

## 2. Supported Scope / 支持范围

V0.2 Python 原型只支持：

- 单文件 `.py`；
- 在线粘贴代码或上传 `.py`；
- 简单输入输出题；
- 固定测试用例；
- 捕获 `stdout`；
- 捕获 `stderr`；
- 超时控制；
- 基础错误类型识别；
- 教师复核。

适用知识点：

- `print` 输出；
- `input` 输入；
- 变量赋值；
- 基础数据类型；
- `if` 条件判断；
- `for` / `while` 简单循环；
- `def` 函数入门；
- 形参与实参；
- 输入输出格式；
- 简单字符串与数字处理。

## 3. Out of Scope / 不支持范围

V0.2 Python 原型不支持：

- 多文件项目；
- 第三方库；
- 图形界面；
- 网络访问；
- 数据库访问；
- 文件读写题；
- 复杂单元测试框架；
- 长时间运行程序；
- 自动代写答案。

## 4. Workflow / 批阅流程

推荐流程：

```text
学生提交 Python 代码
→ 系统在受限环境中运行
→ 输入测试用例
→ 捕获 stdout / stderr
→ 判断输出是否匹配
→ 识别错误类型
→ 生成初步反馈
→ 教师复核
→ 学生查看最终反馈
→ 记录学习错误数据
```

## 5. Grading Strategy / 批阅策略

Python 基础题原型采用输入输出比对，不采用复杂单元测试框架。

建议策略：

1. 教师创建题目，填写题干、起始代码、固定测试输入和期望输出。
2. 学生提交 `.py` 文件或粘贴代码。
3. 系统在受限运行环境中执行代码。
4. 对每组测试用例注入标准输入。
5. 捕获 `stdout`、`stderr`、退出状态和运行时间。
6. 将输出与期望输出比较。
7. 初步判断正确、答案错误、格式错误、运行异常或超时。
8. 教师复核最终得分和反馈。

输出比对可以先支持：

- 完全匹配；
- 去除首尾空白后匹配；
- 按行比较；
- 基础数字字符串比较。

## 6. Error Tags / 错误标签

基础错误标签：

| 标签 | 含义 |
|---|---|
| SyntaxError | 语法错误 |
| NameError | 变量未定义 |
| TypeError | 类型错误 |
| ValueError | 值错误 |
| IndexError | 索引错误 |
| ZeroDivisionError | 除零错误 |
| Timeout | 运行超时 |
| WrongAnswer | 答案错误 |
| FormatError | 输出格式错误 |
| LogicError | 疑似逻辑错误 |
| FunctionCallError | 函数调用错误 |
| ParameterError | 形参与实参理解错误 |
| InputOutputError | 输入输出理解错误 |

## 7. Safety Notes / 安全说明

Python 代码执行必须受限：

- 设置运行超时；
- 不允许网络访问；
- 不允许数据库访问；
- 不设计文件读写题；
- 不允许第三方库依赖；
- 不把学生代码直接作为公开案例数据提交。

V0.2 如果实现该原型，应优先在演示环境中使用虚构学生和脱敏代码样例。

## 8. Data Recording / 数据记录

每次 Python 批阅可以记录：

- 作业 ID；
- 学生 ID；
- 提交代码；
- 测试用例结果；
- `stdout`；
- `stderr`；
- 自动错误标签；
- 系统初评；
- 教师最终评分；
- 教师反馈；
- 教师修正错误标签；
- 是否需要后续辅导；
- 是否可作为脱敏样本进入教学错误数据集。

数据记录的目的不是监控学生，而是帮助教师发现共性误区并改进教学。

## 9. Demo Questions / 演示题目范围

V0.2 Python MVP 只演示 1-2 道基础题，不继续扩展题型。

建议演示题：

1. `input + if` 判断题：输入成绩，判断是否及格。
2. `for` 循环求和题：输入 `n`，计算 `1` 到 `n` 的和。

这两类题足够展示：

- 输入处理；
- 条件判断；
- 循环；
- `stdout` 捕获；
- 错误类型识别；
- 教师复核。

不要在 V0.2 中继续扩展到列表综合题、文件读写题、多函数项目题、第三方库题或复杂算法题。

## 10. Teacher Annotation Rule / 教师标注规则

V0.2 的教师错误标注采用：

- 主错误类型：单选；
- 教师补充说明：文本。

第一版只要求教师选择一个“主要错误”。后续版本可扩展多标签，但 V0.2 不做多标签，避免页面、统计和教师操作复杂化。

## 11. Dataset Consent Default / 数据集进入默认值

`can_enter_dataset` 必须默认 `false`。

只有教师明确手动勾选后，该提交才允许作为脱敏样本进入教学错误数据集。该设计用于体现学生数据安全、教师责任边界和案例公开发布的谨慎原则。
