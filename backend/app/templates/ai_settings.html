模型配置说明

模型列表由服务端环境变量 DEEPSEEK_ALLOWED_MODELS 配置，默认模型由 DEEPSEEK_DEFAULT_MODEL 配置。

本地开发时通常在项目根目录 .env 中配置，示例变量见 .env.example；生产部署时建议使用服务器环境变量。

请不要在 .env、.env.example、日志或 Git 中提交真实 API Key。如 DeepSeek 官方模型名称变化，可由管理员更新环境变量后重启服务。

模型选用建议：deepseek-v4-pro 更适合知识主干生成、课程思政与职业素养融入点、正式案例展示和争议样本复核；deepseek-v4-flash 更适合日常快速预览、批量反馈初稿和调试页面流程。知识主干正式演示建议优先使用 deepseek-v4-pro，批量反馈或调试建议优先使用 deepseek-v4-flash。
